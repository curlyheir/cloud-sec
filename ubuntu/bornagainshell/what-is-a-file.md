# what is a file?

In Linux, a file is a named collection of related data that appears to the user as a single, contiguous block of information and is retained in storage.  Under the "Everything is a File" philosophy, this concept extends beyond standard documents to include directories, hardware devices (like hard drives and printers), network sockets, and inter-process communication channels. 

Linux categorizes files into several primary types:

Regular files: Contain data, text, or program instructions (e.g., text documents, binary executables). 

Directories: Special files that contain lists of other files and directories, organizing the file system hierarchy. 

Special files: Include block devices (accessed in fixed-size chunks, like hard drives), character devices (accessed byte-by-byte, like keyboards or /dev/null), symbolic links, named pipes (FIFOs), and sockets for inter-process communication.
